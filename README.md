## 📌 Project Description

### 📝 Short Summary
A comprehensive Weather Analytics and Forecasting System evaluating climate trends across **6 key Egyptian Governorates** (Cairo, Giza, Alexandria, Minya, Luxor, Aswan). The project integrates data collection, advanced SQL transformations, interactive Power BI visualizations, and Machine Learning predictive models to forecast environmental metrics and assess sector-specific impacts.

---

### 🔑 Key Features & Highlights

* **Multi-Regional Climate Analysis:** Analyzed historical weather data across 6 diverse Egyptian governorates to identify regional climate variations and environmental trends.
* **Predictive Forecasting (Machine Learning):** Built ML models using Python to forecast future weather metrics (temperature variations, precipitation patterns, and humidity levels) for actionable decision-making.
* **Interactive Power BI Dashboards:** Designed a multi-page interactive dashboard (including Executive Summary, Temporal Trends, Sector Impact, and Regional Breakdown) featuring custom bookmarks, dynamic slicers, and seamless navigation.
* **Data Engineering & ETL:** Automated data extraction, cleaned complex environmental datasets, and optimized database queries using SQL Server for smooth dashboard integration.
* **Sector Impact Insights:** Derived strategic insights on how weather anomalies affect vital sectors such as Agriculture, Energy Consumption, and Public Safety.

---

### 🛠️ Tech Stack & Tools

* **Data Analysis & ML:** Python (`pandas`, `scikit-learn`, `matplotlib`, `seaborn`)
* **Database Management:** SQL Server (Data Cleaning, Query Optimization, Dynamic Views)
* **Data Visualization:** Power BI (DAX Measures, Data Modeling, Custom Visuals & UX Design)
* **Documentation & Version Control:** Git & GitHub
