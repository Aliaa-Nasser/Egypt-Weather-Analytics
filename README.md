# 🌤️ Egypt Weather Analytics & Predictive System

An interactive Power BI Dashboard and Predictive Analysis project evaluating weather patterns across 6 Egyptian Governorates (Cairo, Giza, Alexandria, Minya, Luxor, Aswan). 

Developed as part of the **National Telecommunication Institute (NTI)** training program, receiving full marks and top honors at the final defense.
